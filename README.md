# AI Background Generator

Uma ferramenta web interativa para **gerar backgrounds dinâmicos com Inteligência Artificial**, combinando cores vibrantes, gradientes e efeitos visuais para criar experiências modernas e personalizadas para projetos web.

O projeto utiliza **HTML, CSS e JavaScript** para construir uma interface dinâmica, integrada ao **n8n** para automatizar o fluxo de geração de backgrounds com IA. Cada resultado pode ser visualizado diretamente na interface e acompanhado de seu código HTML e CSS, permitindo que o usuário experimente diferentes estilos e aplique o background gerado em seus próprios projetos.

## 🔄 Fluxo de Funcionamento

1. **Solicitação:** O usuário informa um estilo de background que deseja criar em forma de prompt na interface do sistema.
2. **Processamento:** a aplicação envia os dados necessários ao workflow configurado no n8n.
3. **Geração:** o fluxo automatizado aciona os recursos de Inteligência Artificial para produzir o resultado.
4. **Visualização:** o background gerado é aplicado à interface para que o usuário avalie sua aparência.
5. **Exportação:** o usuário consulta e copia o código HTML e CSS disponibilizado para reutilizá-lo em seu próprio projeto.
